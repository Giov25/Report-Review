# Report review

Review page for the v33-resnet-masks-noclaim test reports (141 cases): the four MRI sequences,
the generated reports and the competitors' ones, the four checkable claims, a
0-5 rating and notes.

**Open:** https://giov25.github.io/report-review/

This repository holds only the page. The data are in the private repository
`Giov25/report-review-data`; the page asks for a GitHub token that can read and write
it, and saves your review in `reviews/<your name>.json` there.

## Token

Either of:

- a token shared by the owner (a fine-grained token for `Giov25/report-review-data`
  only, permission *Contents: Read and write*);
- your own **classic** token with the `repo` scope, once you have accepted the
  invitation to `Giov25/report-review-data` (fine-grained tokens cannot reach a
  repository where you are only a collaborator).

The token stays in your browser (only if you tick *Remember*) and is sent only
to api.github.com.
